# Image Downloader

Desktop GUI image downloader built with Python, featuring PyQt5 and Tkinter implementations.

## Features

- **Wallpaper Shortcuts:** Direct shortcuts to wallpaper platforms (WallpaperCave, HDWallpapers, AlphaCoders, Supercars).
- **Directory Selection:** Choose download destination via native directory dialog.
- **Automated Scraping:** Automates downloading via CLI scrapers using PyAutoGUI.
- **Dual Implementations:** Available in both PyQt5 and Tkinter interfaces.

## Requirements

- Python 3.x
- PyQt5
- PyAutoGUI
